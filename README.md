# one-line-laugh-01

A single funny line for the make.fun "The One-Line Laugh" bounty. The entry
program (`main.py`, pure Python 3 standard library, no network, no input)
writes exactly one sentence to `/output/entry.txt`: a family that finally
talks to each other when the Wi-Fi goes down — and unanimously agrees it
was the worst ten minutes of the week. The joke lands on a real surprise
at the end that still makes sense, and an everyday truth anyone who has
lived through a Wi-Fi outage will recognise.
